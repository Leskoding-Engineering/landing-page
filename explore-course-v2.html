7 konsep baru untuk Program Belajar.

Data 9 program (usia, tools, karya, silabus) diambil dari Knowledge Base §6, dan warna per program sama dengan kartu di index.html. Setiap opsi punya tombol detail dan CTA Coba Kelas Gratis, jadi bisa menggantikan modal silabus yang sekarang.

OPSI 1

Peta Jalur MRT

Kurikulum digambar seperti peta kereta. Jalur Fondasi berjenjang, jalur Skill Digital fleksibel, dan 4 cabang Teens bercabang dari stasiun "Asesmen Free Trial". Langsung terlihat bahwa remaja 11+ boleh masuk tanpa prasyarat.

Program Belajar.

Dirancang bertahap untuk usia 6–17 tahun. Kurikulum berbasis proyek nyata dan pendampingan tutor berpengalaman.

OPSI 2

Rak Kaset Game

Setiap program jadi kaset game. Pilih kaset, layar "menyala", lalu silabus tampil sebagai level, karya sebagai achievement, dan tools sebagai equipment.

Pilih Kaset Belajarmu.

LESKODING · LAB
OPSI 3

Kartu Koleksi

Program tampil seperti trading card dengan efek holo. Sisi depan memuat karya yang dibuat, tools, dan posisi di jalur (jenjang / fleksibel / tanpa prasyarat). Klik kartu untuk membaliknya: sisi belakang berisi silabus dan "setelah ini lanjut ke mana".

Program Belajar.

Klik kartu untuk melihat silabus.

OPSI 4

Rentang Usia

Semua program dipetakan di sumbu usia 6–17 seperti timeline. Geser penanda usia, program yang tidak cocok meredup. Ini menjawab pertanyaan orang tua nomor satu: "anak saya umur sekian, bisa ikut apa?"

Program Belajar.

Geser untuk melihat program sesuai usia anak.

OPSI 5

Mau Bikin Apa?

Dimulai dari hasil karya, bukan nama kelas. Anak (atau orang tua) memilih "mau bikin game / website / robot…", lalu muncul mockup karya itu dan program yang mengajarkannya.

Si kecil mau bikin game_

OPSI 6

Tabel Periodik Program

Nuansa "lab sains" dari Playful Future Lab. Setiap program adalah elemen dengan simbol 2 huruf, nomor, dan rentang usia. Hover atau klik elemen untuk menampilkan detail besar di tengah tabel.

Program Belajar.

9 "elemen" pembentuk inovator kecil. Kombinasikan sesuai minat dan usia.

OPSI 7

Peta + List Kartu (gabungan opsi 1 & 3)

Satu section, dua lapis. Peta jalur di atas memberi gambaran besar, list kartu di bawah dikelompokkan per jalur dengan warna yang sama. Keduanya saling terhubung: klik stasiun untuk lompat ke kartunya, hover kartu untuk menyalakan stasiunnya di peta, dan filter berlaku untuk peta dan list sekaligus.

Program Belajar.

Dirancang bertahap untuk usia 6–17 tahun. Kurikulum berbasis proyek nyata dan pendampingan tutor berpengalaman.
